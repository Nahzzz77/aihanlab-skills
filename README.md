# AiHanLab Skills

面向 AI 内容创作与知识表达的可复用 Skill 集合。

## 当前 Skill

### `aihanlab-xhs-knowledge-notes`

用于制作面向 AI 初学者的小红书知识图解、概念词解和多图笔记。

它负责：

- 从关键词、长文本、截图和文件中判断选题重点
- 对 AI 概念进行事实核验和交叉验证
- 组织故事化、结构清晰的知识脚本
- 规划 3:4 竖版多图内容
- 生成标题、正文、话题标签和评论区互动问题
- 统一 AiHanLab 的视觉与排版规范

Skill 文件：

[查看 SKILL.md](.codex/skills/aihanlab-xhs-knowledge-notes/SKILL.md)

### `human-writing`

通用中文创作与改稿 Skill，适用于知乎回答、论坛长帖、公众号文章、博客、评论、人物故事、历史叙事、新闻与行业解读、科普、教程、评测、个人叙事、小说、对白、口播和演讲稿。

它负责：

- 先检查现实写作的材料是否足够，避免用重复解释凑篇幅
- 区分现实写作、虚构创作和混合创作的事实边界
- 保留自然中文韵律、具体细节和清晰判断
- 清理机构腔、营销腔、模型腔和常见翻案句
- 提供论坛长帖、现实题材、虚构创作、特殊格式和改稿参考规则
- 通过脚本检查成稿中的硬性写作禁令

Skill 文件：

[查看 SKILL.md](.codex/skills/human-writing/SKILL.md)

## 触发方式

你可以这样调用：

- “帮我做一篇小红书 AI 知识笔记”
- “把 Agent 做成小红书图文”
- “帮我分析这段材料适合发什么”
- “把这张截图整理成知识图解”
- “做一期 RAG / AIGC / AI 入门内容”

## 内容规范

- 面向对 AI 感兴趣的初学者
- 先做选题判断，再开始制作
- 涉及专业定义时先搜索并交叉验证
- 默认至少 4 张 3:4 竖版图片
- 首张为封面，固定角标包括 `2026`、`AiHanLab`、`AI` 和不超过 5 个字的关键词
- 正文默认不超过 300 字，使用短段落、口语化表达和适量 Emoji
- 视觉素材服务于知识表达，优先保证结构清晰和文字可读
